# Power transmission

**Question:** Why does stepping voltage up reduce line heating?

This Phase 11 Gallery fixture executes `runFieldScenario("power-transmission")` through the same deterministic `@physica/physics-fields` API used by the desktop workflow. Values are SI-canonical.

## Assumptions

- fixed transmitted input power
- purely resistive line

## Representations

- step-up transformer
- transmission line
- power-flow panel

The checked-in SVG is an accessible deterministic preview. Final packaged `.physica`, PNG and WebM artifacts remain tracked for the shared Phase 20 export pipeline.
