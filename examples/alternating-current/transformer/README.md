# Ideal transformer

**Question:** How do turns set voltage, current and conserved ideal power?

This Phase 11 Gallery fixture executes `runFieldScenario("transformer")` through the same deterministic `@physica/physics-fields` API used by the desktop workflow. Values are SI-canonical.

## Assumptions

- ideal transformer
- no leakage or resistive loss

## Representations

- transformer core
- primary and secondary coils
- input/output waveforms

The checked-in SVG is an accessible deterministic preview. Final packaged `.physica`, PNG and WebM artifacts remain tracked for the shared Phase 20 export pipeline.
