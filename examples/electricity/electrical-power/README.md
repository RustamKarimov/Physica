# Electrical power

**Physical question:** Why do three equivalent power expressions agree for an ohmic load?

This Phase 10 Gallery project executes the public `runElectricityScenario` API. Its schematic, readings, graph and expected JSON derive from the same deterministic electrical state.

## Assumptions

- ohmic load
- steady D.C.

## Representations

- energy-flow arrows
- power meter
- equation panel
