# Read gradient from the same curve

This example resolves a tangent at 1 second from the same piecewise-linear height curve that is drawn. The centred secant gives a gradient of 4 m/s, the triangle shows a 1 s run and 4 m rise, and the maximum is the stable measured point at 2 s.

No quadratic curve or calculus result is fabricated beyond the declared sampled model.
