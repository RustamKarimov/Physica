# Single-slit diffraction

**Physical question:** How does aperture width set the diffraction envelope?

This Phase 9 Gallery project executes the public `runOpticsScenario` scenario. Its expected JSON, accessible SVG and future packaged artifacts all derive from the same deterministic parameters.

## Assumptions

- Fraunhofer far field
- monochromatic scalar wave

## Representations

- slit geometry
- screen intensity
- diffraction graph

Final `.physica`, PNG and WebM capture is declared for the shared Phase 20 pipeline.
