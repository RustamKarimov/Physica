# Electric potential

**Question:** How does potential change with distance from a charge?

This Phase 11 Gallery fixture executes `runFieldScenario("electric-potential")` through the same deterministic `@physica/physics-fields` API used by the desktop workflow. Values are SI-canonical.

## Assumptions

- zero potential at infinity
- electrostatic point charge

## Representations

- equipotential curves
- potential graph
- field probe

The checked-in SVG is an accessible deterministic preview. Final packaged `.physica`, PNG and WebM artifacts remain tracked for the shared Phase 20 export pipeline.
