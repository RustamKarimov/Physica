# Point-charge field

**Question:** How does a positive charge set field direction and magnitude?

This Phase 11 Gallery fixture executes `runFieldScenario("point-charge-field")` through the same deterministic `@physica/physics-fields` API used by the desktop workflow. Values are SI-canonical.

## Assumptions

- electrostatic point charge
- vacuum

## Representations

- positive charge
- field lines
- vector-field probe

The checked-in SVG is an accessible deterministic preview. Final packaged `.physica`, PNG and WebM artifacts remain tracked for the shared Phase 20 export pipeline.
