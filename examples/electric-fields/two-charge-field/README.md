# Two-charge electric field

**Question:** How do vector contributions form a dipole field?

This Phase 11 Gallery fixture executes `runFieldScenario("two-charge-field")` through the same deterministic `@physica/physics-fields` API used by the desktop workflow. Values are SI-canonical.

## Assumptions

- electrostatic point charges
- linear superposition

## Representations

- positive and negative charge
- field lines
- vector grid

The checked-in SVG is an accessible deterministic preview. Final packaged `.physica`, PNG and WebM artifacts remain tracked for the shared Phase 20 export pipeline.
