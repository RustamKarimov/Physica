# Electron between parallel plates

**Question:** How does a uniform electric field deflect an electron?

This Phase 11 Gallery fixture executes `runFieldScenario("charged-particle-plates")` through the same deterministic `@physica/physics-fields` API used by the desktop workflow. Values are SI-canonical.

## Assumptions

- uniform field
- non-relativistic
- gravity neglected

## Representations

- parallel plates
- electron
- force vector
- trajectory
