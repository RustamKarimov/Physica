# Potential divider

**Physical question:** How does the resistor ratio set the measured output potential?

This Phase 10 Gallery project executes the public `runElectricityScenario` API. Its schematic, readings, graph and expected JSON derive from the same deterministic electrical state.

## Assumptions

- unloaded output
- ideal voltmeter

## Representations

- divider schematic
- slider marker
- voltmeter
- ratio equation

Final `.physica`, PNG and WebM capture is declared for the shared Phase 20 pipeline.
