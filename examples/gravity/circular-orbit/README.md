# Circular Earth orbit

**Question:** How do altitude, speed, period and energy remain linked?

This Phase 11 Gallery fixture executes `runFieldScenario("circular-orbit")` through the same deterministic `@physica/physics-fields` API used by the desktop workflow. Values are SI-canonical.

## Assumptions

- circular Newtonian orbit
- Earth fixed at origin

## Representations

- orbit
- velocity vector
- energy bars
- period clock

The checked-in SVG is an accessible deterministic preview. Final packaged `.physica`, PNG and WebM artifacts remain tracked for the shared Phase 20 export pipeline.
