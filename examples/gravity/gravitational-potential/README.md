# Gravitational potential

**Question:** How are potential and field connected outside Earth?

This Phase 11 Gallery fixture executes `runFieldScenario("gravitational-potential")` through the same deterministic `@physica/physics-fields` API used by the desktop workflow. Values are SI-canonical.

## Assumptions

- zero potential at infinity
- spherical Earth

## Representations

- potential curve
- equipotential shells
- field arrow

The checked-in SVG is an accessible deterministic preview. Final packaged `.physica`, PNG and WebM artifacts remain tracked for the shared Phase 20 export pipeline.
