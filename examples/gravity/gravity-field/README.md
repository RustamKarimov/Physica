# Earth gravitational field

**Question:** How do direction and magnitude change around a spherical source?

This Phase 11 Gallery fixture executes `runFieldScenario("gravity-field")` through the same deterministic `@physica/physics-fields` API used by the desktop workflow. Values are SI-canonical.

## Assumptions

- Newtonian point-mass exterior field
- Earth treated as spherical

## Representations

- Earth
- field-vector grid
- field lines
- moving probe

The checked-in SVG is an accessible deterministic preview. Final packaged `.physica`, PNG and WebM artifacts remain tracked for the shared Phase 20 export pipeline.
