# Synchronized SHM views

**Question:** How do position, derivatives, force and energy remain synchronized while scrubbing?

This Phase 13 Gallery fixture executes the public deterministic @physica/physics-mechanics oscillation API used by the desktop. All values are SI-canonical and every linked view shares model time.

## Assumptions

- linear restoring force
- no damping
- constant mass

## Representations

- mass and spring
- x/v/a/force followers
- linked time graphs
- energy bars

The checked-in SVG is an accessible deterministic preview. Final packaged .physica, PNG and WebM artifacts remain tracked for Phase 20.
