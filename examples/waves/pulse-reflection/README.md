# Pulse reflection at a boundary

**Physical question:** How does an impedance change divide reflected and transmitted energy?

This Phase 9 Gallery project executes the public `runWaveScenario` scenario. Its expected JSON, accessible SVG and future packaged artifacts all derive from the same deterministic parameters.

## Assumptions

- lossless ideal boundary
- one-dimensional scalar pulse

## Representations

- incident pulse
- reflected pulse
- transmitted pulse

Final `.physica`, PNG and WebM capture is declared for the shared Phase 20 pipeline.
