# Electromagnetic induction

**Question:** How does changing flux linkage determine emf and polarity?

This Phase 11 Gallery fixture executes `runFieldScenario("electromagnetic-induction")` through the same deterministic `@physica/physics-fields` API used by the desktop workflow. Values are SI-canonical.

## Assumptions

- uniform flux through every turn
- constant rate over interval

## Representations

- coil pair
- flux surface
- emf graph
- polarity arrow

The checked-in SVG is an accessible deterministic preview. Final packaged `.physica`, PNG and WebM artifacts remain tracked for the shared Phase 20 export pipeline.
