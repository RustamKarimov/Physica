# Force on a current

**Question:** How do B, I, length and orientation set wire force?

This Phase 11 Gallery fixture executes `runFieldScenario("force-on-current")` through the same deterministic `@physica/physics-fields` API used by the desktop workflow. Values are SI-canonical.

## Assumptions

- uniform magnetic field
- straight active wire segment

## Representations

- wire
- current direction
- B field
- force vector

The checked-in SVG is an accessible deterministic preview. Final packaged `.physica`, PNG and WebM artifacts remain tracked for the shared Phase 20 export pipeline.
