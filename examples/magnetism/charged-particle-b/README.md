# Charged particle in uniform B

**Question:** Why does magnetic force curve the path without changing speed?

This Phase 11 Gallery fixture executes `runFieldScenario("charged-particle-b")` through the same deterministic `@physica/physics-fields` API used by the desktop workflow. Values are SI-canonical.

## Assumptions

- velocity perpendicular to uniform B
- non-relativistic

## Representations

- particle path
- velocity vector
- force vector
- B markers

The checked-in SVG is an accessible deterministic preview. Final packaged `.physica`, PNG and WebM artifacts remain tracked for the shared Phase 20 export pipeline.
