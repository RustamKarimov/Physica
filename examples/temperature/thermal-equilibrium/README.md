# Two-body thermal equilibrium

**Question:** How do two isolated bodies approach a shared temperature?

This Phase 12 Gallery fixture executes the public deterministic @physica/physics-thermal scenario API used by the desktop workflow. Values are SI-canonical and the model disclosure is retained.

## Assumptions

- constant heat capacities
- isolated two-body system

## Representations

- two thermal blocks
- thermal contact
- temperature-time graph

The checked-in SVG is an accessible deterministic preview. Final packaged .physica, PNG and WebM artifacts remain tracked for the shared Phase 20 export pipeline.
