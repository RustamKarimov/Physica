# Coordinate spaces

This non-rendered executable foundation example transforms a point from a rotating, moving local frame into the physical world at an explicit time and back again. It also proves the canonical 2D `z=0` plane and the required not-to-scale warning for educational scaling.

The checked-in SVG is descriptive metadata, not output from a renderer. `pending-artifacts.json` records the upgrade required after renderer and shared example-runtime infrastructure exist.
