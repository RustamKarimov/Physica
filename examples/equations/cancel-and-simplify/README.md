# Cancel clutter, preserve meaning

This Phase 4 Step 4.2 example simplifies `x+(y-y)` to `x`. The canonical source deliberately retains the cancelling pair, and the pinned symbolic engine establishes expression equality before Physica records `VERIFIED_EQUIVALENT`. Removed structural fragments are explicit exits rather than a screenshot crossfade.

The executable output evaluates a deterministic FLIP/exit plan at exact progress coordinates, checks reduced motion and round-trips the V1 transform definition.

Run it from the repository root with `pnpm vitest run examples/equations/cancel-and-simplify`.
