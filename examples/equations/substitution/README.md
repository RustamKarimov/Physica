# Substitute values with proof attached

This Phase 4 Step 4.2 example applies `u=3`, `t=4` and `a=2` to `s=ut+\frac{1}{2}at^2` and verifies the target `s=28`. The substitution map is explicit persisted document data; only the pinned symbolic engine may assign `VERIFIED_SUBSTITUTION`.

The semantic matcher independently proposes which fragments persist and which symbols exit while the numerical value enters. Correspondence never substitutes for verification.

Run it from the repository root with `pnpm vitest run examples/equations/substitution`.
